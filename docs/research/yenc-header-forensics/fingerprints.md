Notes on the table:
- Single-part handling: only Nyuu always writes part= and total=. Other tools omit total= or crc32= on single-part posts. Use this, not the Message-ID, to separate Nyuu from its imitators.
- Article size is a within-tool filter only. Across tools the encoded size shifts by fixed offsets: Nyuu edge escaping about +113 B, nxg 0x7F about +2900 B (Haiku W4). The 716800 value is shared by Nyuu and ngPost, so size alone does not separate them.
- Validity check for every row: an article fingerprint is only trusted after strict yEnc validation (begin/end 1-based, size == end-begin+1, part <= total, parse hex as numbers).
