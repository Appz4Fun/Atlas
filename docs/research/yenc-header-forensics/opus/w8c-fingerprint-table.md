Merged 2026-11-02 from opus/w1a, w1b, w2a, w2b, w2c, w3b, w3c, w4a, w4b, w5a-c, w6a-c, w7a-c; the sibling ../fingerprints.md (F), ../log.md, ../wave07.md, ../wave08.md, ../raw/w08-c-rust-spec.md (RS); and grep of ../../linking-findings.md (LF). No new web research and no third-party code was run. Sibling files were only read.

Tags: SRC = source line read, MEAS = measured on real NZBs/articles, DOC = docs, INF = inferred. "n/r" = not recorded. MID = Message-ID. Regexes are for the MID without `<>`.

Link-method key: **RNG** = PRNG state solve (cost, draws); **DET** = deterministic/derivable IDs; **TIME** = timestamp in MID or Date; **FP** = fingerprint only (tool/uploader label, no session link); **SRV** = server-assigned ID carries session data.

## 5. Classifier order (Rust, on XOVER then HEAD)

Cheapest and most specific first; first match labels, later steps only refine.

1. **Fixture/invalid filter**: no `@`, test hosts (RS `is_fixture_host`).
2. **Server-assigned families** (exact, cheap, high value): Highwinds fxNN (extract T1/N/K), Diablo `$`, INN radix32 `$`, Giganews, `@UFK`. These label the *injector*, not the tool: keep going to steps 6-7 for tool tells.
3. **Literal-domain tools**: `@nyuu` (strict case alternation, else NyuuLoose/NewsUP fake), `@ngPost`, `$gps@gopoststuff` (vs `@gpoststuff` = NewsUP), `@JBinUp.local` (`_NoM` real vs 32-char fake), `@JBinDown.local`, `@powerpost2000AA.local` / `@camelsystem-powerpost.local` (check N<=M and 20 vs 22 chars), `.newsup`, `@riverup`, `.geri`, `@spot.net`, `[0-9]{10}\.local` (yEncBin), `@PRiVATE`.
4. **Structured shapes**: Nyuu-shape other host; newsmangler `epoch.5dp.part@host`; `part{n}of{N}.{hex32}@` (keimpema); 40@21.3 hex (nxg: verify by deriving from header if NXG link known); dashed v4 UUID (usenet-posting).
5. **Ambiguous random shapes**: `32@8.3` alnum -> postie vs Nyuu-Obf (needs HEAD/body: Date `GMT` + fixed order + even-length hex name = Nyuu-Obf; `UTC`/`+0000`, 750000 size, no crc32 = postie); 32-hex -> v4 nibble test (ngPost custom sig) / server host (nntpPoster) / else pesto. Unknown -> `Unknown` with per-From cluster.
6. **XOVER cross-checks** (free): From shape (`[A-Za-z0-9]{13}@ngPost.com`, `NewsUP@somewhere.cbr`, `yEncBin@Poster.com`, `{14} <{14}@{5}.{3}>`, user@host); Date present vs MID ms (Nyuu: |Date - ms/1000| < 1 s unless Farm); Subject templates (`yEnc` absent -> NewsUP/PowerPost; ngPost -x Subject == MID local); `:lines` per part size.
7. **HEAD** (one per file, only if still ambiguous): header order and set (Nyuu: MID first + User-Agent; ngPost 4 headers; GoPostStuff/newsmangler X-Newsposter; yEnc32 X-Newsreader; SuperPoster Organization turboPoster; nxg-upper no Newsgroups + X-Nxg), after normalisation in section 4.
8. **BODY first lines** (one article per file, optional): `=ybegin/=ypart/=yend` field sets, pcrc32 padding/case, crc32 on last part, trailing space after name=, blank line before `=yend`, 129-char lines: separates ngPost <=v5.5 / Hydro / NewsUP / Nyuu / postie / yEnc32 / PowerPost even when the MID is faked or server-assigned.
9. **Linking dispatch by label**: Nyuu -> V8 solver (new-V8 first; old-V8 fallback = TIME only); Nyuu-Obf -> 68-char Subject+From solver; NewsUP own -> drand48 inverter; ngPost -> From seed brute force (ms window for <= v4.14, 2^32 or Windows seed-1 table for >= v4.15); nxg/geri/keimpema -> DET; Highwinds -> (host,K,T1,N); GoPostStuff/newsmangler/Upstream/yEncBin/NewsUP -> TIME adjacency; rest -> FP only.
