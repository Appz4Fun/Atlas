NZB writer table (tool vs signature):

- ngPost: UTF-8, 2-space, LF, @ngPost IDs, bytes = decoded 716800.
- Binsearch: iso-8859-1, DOCTYPE 1.0, comment "NZB Generated by Binsearch.info (fcgi)", keeps original IDs.
- NZBIndex: DOCTYPE 1.0, comment "NZB Generated by NZBIndex".
- newznab: no XML decl, comment "generated by newznab 0.2.3pz", meta category/name/propername. nZEDb: comment "NZB Generated by: nZEDb 0.6.8.1". NZBgeek: "Provided by NZBgeek".
- .NET re-serialization (Sonarr/Radarr/Prowlarr fixture): BOM, attr order date,poster,subject.
- Old newzbin: attr order subject,date,poster, comment "Generated at http://www.newzbin.com - <unix>", @powerpost2000AA.local IDs.
- Session features: ID ms, gap distribution, throughput, date skew, file-boundary gaps. Tool features: decl case, DOCTYPE, attr order, indent, EOL, comments, meta keys, ID template. Uploader: poster, segment size.
