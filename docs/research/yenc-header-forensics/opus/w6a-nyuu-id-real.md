# Wave 6A: stock Nyuu Message-ID solver on real NZBs (Opus subagent + corpus run)
- Stock Nyuu ID = 24 Math.random draws alternating 65+x*26 / 97+x*26 (animetosho/Nyuu lib/article.js:199-228) + -<ms>@nyuu. Two IDs (48 draws, ~4.7 bits each) solve V8 state. Solver: nyuu-id-solver/nyuuid_solve.py (sort by ms, try pairs among first 10, GF(2), 64-entry LIFO cache model, regenerate fwd/back). Synthetic 40/40.
