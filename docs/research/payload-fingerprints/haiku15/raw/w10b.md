# W10B inner-file CRC alt keys (11:00Z)
- RAR5 (technote): data CRC32 (flag 0x0004) = unpacked CRC, except split parts: non-last parts hold CRC of the packed chunk; last part = whole-file. BLAKE2sp (32 B) in file hash extra record; last part = unpacked hash. Encryption flag 0x0002 = tweaked (key-dependent) CRC32 and BLAKE2sp.
- RAR4: FILE_CRC plain even when encrypted (arcread.cpp); split flags 0x0001/0x0002; whole-file CRC in last part (inferred, matches pyrescene 168).
- 7z: SubStreamsInfo kSize/kCRC, usually inside the compressed EncodedHeader at the end; needs LZMA decode of the tail.
- ZIP: bit 3 -> local CRC 0, real in data descriptor/central directory; AE-2 CRC = 0, AE-1 keeps it.
- gzip trailer CRC32 + ISIZE; xz per-block check over uncompressed data (single-block CRC32 stream = file CRC32); tar none.
- Reach: split RAR/7z/ZIP need the LAST article; single-volume RAR and zip -0 (no descriptor) have it in article 1.
