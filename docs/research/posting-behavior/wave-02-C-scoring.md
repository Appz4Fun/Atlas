# Wave 2 C: scoring and validation (07:17-07:26Z)

1. Fellegi-Sunter with term-frequency adjustment: common part sizes (716800/128) weigh little, rare ones a lot; floor u. Correlated tool fields (Message-ID shape, From domain, line length) = ONE "tool fingerprint" comparison (Winkler: EM inflates correlated fields). Rust: weldrs (batch, Polars, EM, blocking, union-find). https://docs.rs/crate/weldrs/latest/source/README.md https://moj-analytical-services.github.io/splink/settings_dict_guide.html (2, high)
2. Label-free u for time closeness: P = 1 - (1 + 2tau/T)^-(N+1) for N articles in T s per group/hour; multiply across groups. https://arxiv.org/pdf/2011.13787 (4, med-high)
3. Avoid transitive closure: it dropped F1 0.54->0.00 in a 2026 ER paper; use best-neighbour attach + merge only if k=3 representative pairs pass + hard vetoes; safe only when pairwise precision >0.9. https://arxiv.org/pdf/2607.26298 . Rust `ena` UnificationTable unify_var_var returns Err on value conflict, with snapshots = union-find with cannot-link (vetoes: different =ybegin total=, duplicate part number with different size, size cap). (3, high)
4. Streaming correlation clustering (Makarychev NeurIPS 2023): keep top-k positive neighbours, O(kn), any edge order. https://arxiv.org/pdf/2305.13560 ; Rust `clump` (batch PIVOT). (4, high)
5. Coordination windows: CooRnet data-driven interval (fastest 10% items, median time to 50% shares; edges >p90); CooRTweet 60/120/600 s, quantile 0.95-0.99; Pacheco ICWSM 2021 30-min bins; Army of Me 15 min, >=3 co-occurrences; CopyCatch (FB patent 9077744). Short windows precise, long add recall; overlapping windows no help (arXiv 2609.21959). Map users->articles/uploads, targets->(group, time bin). (3, high)
6. Session gap: two-Gaussian mixture on log2 inter-arrival; cut at equal likelihood (~1h for web logs). Run per tool-fingerprint stream to split uploads. https://arxiv.org/pdf/1411.2878 (3, medium)
7. PAR2 as ground truth: Recovery Set ID in every .vol; File ID = MD5(md5_16k||len||name); md5_16k content-only links reposts. https://docs.rs/crate/usenet-dl/latest/source/src/parity/par2_metadata.rs (4, high)
8. Baseline: NNTmux sha1(cleaned subject + total files) + Xref merge (CollectionHandler.php).
9. No public binary-header dataset (archive.org/UTZOO text only). Build labels: canary uploads via Nyuu/ngPost; non-obfuscated NZBs from nzbindex/nzbking with subject/From stripped; PAR2 sets.
10. Evaluate by sampling whole clusters (pairwise precision on small benchmarks reads ~1 when true is ~52%); B-cubed, purity, cluster-size distribution. https://arxiv.org/pdf/2210.01230 (3, high)
11. Streaming Bayesian RL (bstrl, arXiv 2307.07005): link each record to its most recent prior occurrence -> repost chains, not cliques. (4, medium)

Pipeline: block (tool fp, group set, 10-min bucket) + sorted neighbourhood on arrival time (DCS++) -> compare (time gap u, tool fp, size/line w/ TF, total/size consistency, injection host, Xref overlap) -> Fellegi-Sunter (u from random pairs, m by EM, prior from certain Message-ID rules) -> online `ena` clustering with vetoes + k-pair confirm -> repost layer keyed on PAR2 md5_16k+len, chained to most recent -> validate on PAR2/canary labels with B-cubed, alarm on giant clusters.
