## Notes

1. NewsUP PAR2 order (the question): the rename PAR2 is built **before** renaming, from real names (`Utils.pm:169`). The main PAR2 is built **after** renaming (`Utils.pm:390-392`). So the main PAR2's FileDesc names are the random 12-char names. The rename PAR2 itself is pushed into the upload list (`Utils.pm:169`) and into the main PAR2 file list, so its real-name packets are what leaks. Note that the tool's own `_generate_random_ids_gopoststuff` mimic has a typo (`gpoststuff`) that differs from GoPostStuff.
2. NewsUP advertises a set of other tools' Message-ID formats for obfuscation (`Utils.pm:710-735`). These are not signatures of those tools: they are NewsUP's own imitation, so a match on them points at NewsUP, not at the named tool.
3. nxg-upper's `ObfuscateYenc` (default false) makes the yEnc name `md5(filename+partnumber)` [S] `yEncEncoder.go:38-46`. Its subject-obfuscate path does not rename files.
4. Not verified (no source read): JBinUp posting code, the Nyuu and ngPost defaults for line length and header order, newspost, the other tools in the list.
