# Wave 6 B: RAR volume chain across groups (Haiku; nzbget RarReader/RarRenamer, ngPost, nxg-upper cloned)
RAR5 (technote + nzbget daemon/postprocess/RarReader.cpp): sig 52 61 72 21 1A 07 01 00; main header archive flags 0x0001 volume, 0x0002 volume-number present (absent => volume 0), 0x0004 solid; volume number vint (RarReader.cpp:343-354). Header flags 0x0008 split-before, 0x0010 split-after. File header: data size, unpacked size, name. End header flag 0x0001 next volume follows. No archive-set ID: identity = (inner name, unpacked size) + chain.
RAR4: sig 52 61 72 21 1A 07 00; main 0x73 flags 0x0001 volume, 0x0010 new numbering, 0x0080 header password; file 0x74 0x0001/0x0002 split before/after; end 0x7b 0x0001 NEXTVOL, 0x0008 VOLNUMBER with 32-bit vol number in END block (tail article needed to order).
NZBGet RarRenamer (RarRenamer.cpp:~206-330): first vol = number 0 and first file not split-before; next = vol last+1, same version, last has next-volume, split flags agree, same inner name; complete when last has no next-vol and not split-after.
Volume sizes: ngPost RAR_SIZE=42 MB (-v42m), RAR_MAX=99 raises size to post/99 (47.8 GiB -> ~494 MiB volumes); nxg-upper min 153600000 B, MaxVolumes 150 (-> ~342 MB); Postie does not RAR.
Join from FIRST article only (RAR5): group by (version, inner name, unpacked size), order by main-header volume number, check equal data size S for non-last volumes and count = ceil(total/S) (sum of data sizes = unpacked only for -m0). Failures: -hp encrypted headers, solid multi-file, RAR4 needs tail, gaps = missing volumes.
